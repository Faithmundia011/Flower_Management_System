🌸 Flower Management System (OFMS)

📘 Overview
The **Flower Management System (OFMS)** is a web-based application designed to simplify the process of managing flower shop operations.  
It allows **customers** to browse and order flowers online, while **administrators** can manage products, orders, users, and generate sales reports.

---

 🚀 Features

👩‍💼 Admin Panel
- Add, edit, and delete flower products  
- Manage customer accounts and orders  
- View and update order statuses (Pending, Processing, Delivered, Cancelled)  
- Generate sales reports in **PDF** and **CSV** format  
- Secure authentication for admin users  

🌸 Customer Dashboard
- Register and log in securely  
- Browse available flowers  
- Place and view orders  
- Pay for orders (supports M-Pesa simulation)  
- Track order status  

---

🛠️ Technologies Used

| Component | Technology |
| Frontend | HTML5, CSS3, JavaScript |
| Backend | PHP (Core PHP with PDO) |
| Database | MySQL |
| Styling | Custom CSS (pastel pink & purple theme) |
| Reporting | ReportLab (PDF generation) |
| Server | XAMPP / Apache |
